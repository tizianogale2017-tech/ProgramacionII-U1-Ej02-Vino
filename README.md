# Vino

Programación II - Unidad 1 - Ejercicio 2

## Consigna
Administrar el inventario de un vino específico, controlando las
entradas y salidas de botellas en stock.

## Lógica
La clase encapsula cuatro atributos privados (`etiqueta`, `varietal`,
`precio`, `stockBotellas`). El constructor valida que el stock inicial
no sea negativo. `venderBotellas(cantidad)` verifica que haya stock
suficiente antes de descontar; `reponerStock(cantidad)` incrementa el
stock. Ambos métodos protegen la coherencia del inventario: nunca puede
quedar en negativo.
